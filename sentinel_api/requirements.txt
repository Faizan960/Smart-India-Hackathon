# Versions are pinned to the SAME set the model artifacts in models/sentinel/ were

# the pytest suite deps are intentionally NOT here.

# cap (the reason it was dropped from the Vercel function), so keeping it makes the

# .method == "shap"). Remove the shap line to ship a lean image; the endpoint still
# works and explanation.method falls back to the labelled attribution.
